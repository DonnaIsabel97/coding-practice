# JavaScript Practice 🟨

This directory contains JavaScript exercises, technical notes, coding challenges, and small experiments designed to strengthen my understanding of the language beyond framework-specific development.

The goal is to develop a deeper understanding of **how JavaScript works**, improve problem-solving skills, and strengthen concepts commonly evaluated during technical interviews.

## 🎯 Goals

* Strengthen JavaScript fundamentals
* Understand JavaScript behavior beyond frameworks
* Practice asynchronous programming
* Improve understanding of scope and execution
* Practice functional programming concepts
* Implement data structures and algorithms
* Strengthen Node.js fundamentals
* Prepare for JavaScript technical interviews

Some exercises are designed specifically to answer questions such as:

* How does a closure work?
* What happens during hoisting?
* How does the event loop execute asynchronous code?
* What's the difference between `==` and `===`?
* How does `this` change depending on context?

These experiments focus on understanding JavaScript behavior rather than simply memorizing definitions.
