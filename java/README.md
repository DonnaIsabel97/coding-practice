## 💻 LeetCode & UMPIRE

For coding challenges, I use the **UMPIRE problem-solving approach**:

* **U — Understand:** Identify requirements, inputs, outputs, constraints, and edge cases.
* **M — Match:** Match the problem with appropriate algorithms, data structures, and patterns.
* **P — Plan:** Develop the solution before coding.
* **I — Implement:** Write a clean Java implementation.
* **R — Review:** Test the solution and check edge cases.
* **E — Evaluate:** Analyze time and space complexity and consider improvements.

The goal is not only to solve problems but to become comfortable **explaining my reasoning during technical interviews**.
