## 💻 LeetCode Practice

LeetCode problems are organized by difficulty and are used to practice common problem-solving patterns and prepare for technical interviews.

For each problem, I will use the UMPIRE problem-solving approach to develop a structured and repeatable way of approaching technical challenges:

    * U — Understand: Clarify the problem, inputs, outputs, constraints, and edge cases.
    * M — Match: Identify relevant data structures, algorithms, and known problem-solving patterns.
    * P — Plan: Develop a step-by-step solution before writing code.
    * I — Implement: Translate the plan into clean Python code.
    * R — Review: Test the solution, identify errors, and verify edge cases.
    * E — Evaluate: Analyze time and space complexity and consider possible improvements.

When revisiting problems, I will focus on understanding the reasoning behind the solution rather than memorizing the answer.
