## LeetCode Practice

Leetcode problems are used to practice common problem-solving patterns and prepare for technical interviews.

For each problem, I will use the UMPIRE problem-solving approach to develop a structure and repeatable way of approaching technical challenges:

    - U -- Understand: clarify the problem, inputs, outputs, contraints and edge cases
    - M -- Match: identify relevant data structures, algorithms and known problem-solving patterns
    - P -- Plan: develop a pseudocode before writing code
    - I -- Implement: translate the plan into clean Python code
    - R -- Review: test the solution, identify errors and verify edge cases
    - E -- Evaluate: analyze time and space complexity and consider possible improvements

When revisiting the problem, I will focus on understanding the reasoning behing the solution rather tahn memorizing the answer.
