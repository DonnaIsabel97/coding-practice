# AWS Practice ☁️

This directory documents my hands-on AWS practice, technical notes, architecture exercises, and cloud experiments.

The goal is to strengthen my understanding of **AWS services, cloud architecture, security, networking, monitoring, and machine learning infrastructure** through practical exercises rather than theory alone.

## 🎯 Goals

* Strengthen AWS fundamentals
* Gain hands-on experience with core AWS services
* Understand how AWS services integrate with one another
* Practice designing cloud architectures
* Improve AWS security and IAM knowledge
* Practice AWS CLI usage
* Understand cloud networking
* Develop troubleshooting skills
* Explore AWS machine learning services and infrastructure

## 🧪 Hands-On Labs

Labs are designed around practical tasks rather than simply reading documentation.

Examples include:

* Create and configure an S3 bucket
* Configure IAM permissions
* Launch and connect to an EC2 instance
* Deploy a Lambda function
* Connect API Gateway to Lambda
* Trigger Lambda from an S3 event
* Configure CloudWatch logs and alarms
* Build a basic VPC
* Interact with AWS services through the CLI
* Deploy a small cloud-based application

## 🏗️ Architecture Practice

Architecture exercises focus on answering questions such as:

* Which AWS service should I use?
* Why is this service appropriate?
* How should these services communicate?
* How can the architecture scale?
* How should access be secured?
* How can the system be monitored?
* What happens if a component fails?
* What could increase cost?

The goal is to understand the **reasoning behind architecture decisions**, not simply memorize AWS services.

## 📝 Lab Documentation

For each significant lab, I aim to document:

### Objective

What am I trying to build or understand?

### Architecture

Which AWS services are involved and how do they interact?

### Implementation

What steps were required to complete the lab?

### Security

What IAM roles, policies, permissions, or network controls were required?

### Problems Encountered

What failed or behaved unexpectedly?

### Solution

How was the issue diagnosed and resolved?

### What I Learned

What concepts became clearer after completing the exercise?

### Cleanup

Which AWS resources need to be removed after the lab to avoid unnecessary charges?
